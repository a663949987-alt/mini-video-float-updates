# 微型短视频播放器

Windows 微型悬浮播放器：启动后连接红果，默认静音，支持右键菜单及鼠标上侧键隐藏或显示。搜狗面板出现时跟随位置；面板消失或切换输入法时仍保持显示。字幕识别暂不包含在此版本中。

右键菜单可调整视频亮度（默认 85%）。播放器隐藏时会尝试暂停红果，重新显示时仅恢复由播放器暂停的视频。
播放器重启后，会根据进程身份恢复自己留下的自动暂停状态，避免把原本正在播放的视频一直停住。

经典皮肤和广告卡片按比例铺满；右键“界面皮肤 → 完整画面（第三版）”将已识别的视频区域按原比例完整放入画框，比例不一致时留黑边。右键“字幕局部放大（试验）”可放大视频底部的画面，关闭后恢复原画面。它不识别或生成文字，可能遮住部分画面或裁掉长字幕的两端。播放器连接红果时会隐藏红果自己的托盘图标。

视频正常播放约五秒后，在任意软件中快速下滚再上滚，可以循环最近五秒的静音画面；再做一次恢复。右上角 × 隐藏面板，鼠标上侧键可重新显示。画面缓存只保存在内存中，循环时字幕局部放大与当前设置一致。视频画面右下角始终显示“广告”，循环时画面有细边框。

右键“选剧 / 选集”打开独立小面板，可搜索短剧、浏览热播榜、本机观看历史和选集。搜索和分集资料使用 [openhongguo](https://github.com/beilunyang/openhongguo) 的匿名设备，不读取红果登录账号；选择后由已连接的红果客户端实际播放。红果界面或服务变化时，无法确认的切换会显示提示。红果由播放器新启动时，会尝试从其观看历史恢复上次剧集；已有运行中的红果不会被自动切换。

右键“缓存管理”可查看下载记录，并尝试缓存当前剧后十集。随机缓存会按批提交下载，借用当前红果窗口切剧并尝试恢复观看，可能影响播放；它并非独立后台下载。默认下载目录接近 9 GiB 或磁盘剩余空间低于 5 GiB 时不再添加任务。由于视频大小在开始下载后才能确定，这不是硬性容量上限。下载内容保存在红果的数据目录，不会自动删除；离线播放和自动切换尚未验证。

右键菜单提供暂停、下一条、静音和音量；对应全局快捷键为 Ctrl+Alt+空格、Ctrl+Alt+右箭头、Ctrl+Alt+上箭头和 Ctrl+Alt+下箭头。“下一条”调用红果默认的下箭头快捷键，需在红果中保留该默认设置。

从 Releases 下载 `MiniVideoFloat-Setup.exe` 安装。安装版启动时和运行期间会检查本仓库的最新正式版；下载完成并通过 GitHub 提供的 SHA-256 校验后自动安装更新。红果本身的更新由红果处理。

项目采用 C#、WPF 和 .NET 8。构建安装包需要 Windows、.NET 8 SDK、Python 3、.NET Framework 4 编译器，以及另行提供的红果发行目录：

```powershell
.\build.ps1 -RedFruitDir 'D:\path\to\hongguo'
```

发布新版本前同步修改 `player/AppUpdater.cs` 中的 `CurrentVersion` 和 `installer/Setup.cs` 中的 `DisplayVersion`，然后创建对应的 `v` 开头的 GitHub Release，并上传名为 `MiniVideoFloat-Setup.exe` 的安装包。
